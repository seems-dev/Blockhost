## 📱 Download the App

Welcome to the official download repository for the **Erex** mobile app!

Erex is the ultimate server management tool for Minecraft Bedrock creators. Our Android app allows you to completely control your servers, manage players, install mods, and monitor real-time performance directly from your phone.

### How to Install

1. Navigate to the **[Releases page](https://github.com/seems-dev/Erex-App/releases/latest)**.
2. Under the **Assets** section of the latest release, download the `app-release.apk` file.
3. Open the downloaded file on your Android device.
4. *Note: If this is your first time installing an app outside of the Google Play Store, your phone may ask you to enable "Install from unknown sources" in your settings.*
5. Follow the on-screen prompts to install the Erex app.

## ✨ Features

- **Live Console:** View real-time server logs and execute commands instantly.
- **Player Management:** Ban, kick, op, and track the XUIDs of all online players.
- **Mod Manager:** Search, install, and configure Add-ons (MCPACK/MCADDON) with one tap.
- **Hardware Metrics:** Monitor live CPU, RAM, and storage utilization.
- **File Editor:** Full access to edit server properties, whitelist configurations, and world files.
- **Automated Backups:** Trigger instant backups or schedule rolling retention backups.
